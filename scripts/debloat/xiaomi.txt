# Xiaomi Mi TV, China firmware. Tried on a MiTV-MFFU0 (Android 14, HyperOS TV).
# Never disable PatchWall (com.mitv.tvhome): this firmware only accepts a system app as home, and without it Home
# lands on a fallback screen that keeps restarting. Keep the settings (com.xiaomi.mitv.settings, com.xiaomi.tvqs),
# the input player (com.xiaomi.mitv.tvplayer), mitv.service and com.mediatek.*, the Sogou keyboard, the updater
# (com.xiaomi.mitv.upgrade), the Xiaomi account, casting (com.xiaomi.miplay, com.xiaomi.mitv.smartshare) and the
# USB player (com.xiaomi.mitv.mediaexplorer).
